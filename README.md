# Vitae — free resume & CV builder

A fast, private resume builder that runs entirely in the browser. No backend, no accounts: resumes are saved to `localStorage`.

- 25 designed templates plus a **Custom layout** builder
  - Templates keep their structure; colors, fonts, sizes, spacing and page settings stay editable
  - Custom layouts unlock everything: one or two columns, header style, photo on/off, stacked/timeline/side-label sections, date placement, divider lines, accent strip, heading styles and sidebar styling. "Customize layout" converts any template into a custom layout that starts from the same look.
- Photo upload with crop, zoom and rotate (only on layouts that have a photo slot)
- Drag and drop for sections, entries and contact fields, including moving sections between the main column and the sidebar
- Live preview with page-break guides, undo/redo (Ctrl+Z / Ctrl+Shift+Z) and autosave
- PDF export through the browser's print engine: vector, selectable text, full-bleed backgrounds and clean page breaks
- JSON export/import (also imports [JSON Resume](https://jsonresume.org/schema) files)
- Mobile-first editor: bottom tab bar and a swipe-to-dismiss preview drawer
- Light and dark themes with a blue-green (teal) accent

## Stack

Vite 8 · React 19 · TypeScript · Tailwind CSS 4 · [shadcn/ui](https://ui.shadcn.com) on Base UI (`base-nova` style) · Motion · React Router 8 · Zustand (persist + zundo undo history) · dnd-kit · react-easy-crop

UI primitives live in `src/components/ui` (generated by the shadcn CLI, owned and lightly extended). App-level composites (labelled fields, switch/slider rows, segmented control, responsive dialog that becomes a drawer on phones, menu helpers) are in `src/components/kit.tsx`. Theme tokens follow shadcn's semantic variables in `src/index.css`.

Add more shadcn components with:

```bash
npx shadcn@latest add <component>
```

## Development

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import the repository in Vercel. It detects Vite automatically: the build command is `npm run build` and the output directory is `dist`. `vercel.json` rewrites every route to `index.html`, so deep links like `/edit/:id` work.

## Project layout

```
src/
  templates/      resume renderer: registry (templates + custom layouts), layouts, resume.css
  features/editor editor panels: content, templates, design (layout builder), layout, drag & drop, photo crop
  pages/          home, template gallery, 404
  store/          Zustand store with localStorage persistence and undo history
  lib/            types, defaults, fonts, markdown-lite, image processing, import/export, theme
  components/     shadcn ui, app kit, live preview, print pipeline, color picker
```

### Notes on PDF output

`Download PDF` opens the browser's print dialog with only the resume visible (`@page { margin: 0 }`). Sidebar backgrounds are drawn with `position: fixed` so they repeat on every page, and per-page margins use `box-decoration-break: clone` (supported in Chrome/Edge 130+ and Firefox). In Safari, pages after the first may have a smaller top margin.
